
# ربات هشدار پرایس‌اکشن سولانا

## قابلیت‌ها
- بررسی توکن‌های سولانایی که کاربر تأیید کرده است.
- دریافت داده از DexScreener و GeckoTerminal.
- استخراج ویژگی‌های پرایس‌اکشن.
- آموزش مدل Logistic Regression روی داده‌های تاریخی.
- ارزیابی زمانی اولیه و ثبت نتایج.
- ارسال هشدارهای احتمالی به تلگرام.
- ذخیره تاریخچه در مخزن GitHub.

## نصب
1. فایل‌ها را در مسیرهای مشخص‌شده قرار دهید.
2. در data/projects.json آدرس توکن واقعی و تأییدشده را وارد کنید.
3. پس از بررسی پروژه، approved_non_meme را true کنید.
4. Secrets تلگرام را در تنظیمات مخزن اضافه کنید.
5. مجوز نوشتن GitHub Actions را فعال کنید.
6. Workflow را از تب Actions اجرا کنید.

## هشدارهای مهم
- این نرم‌افزار سفارش خرید یا فروش ثبت نمی‌کند.
- احتمال پیش‌بینی مدل، احتمال سود قطعی نیست.
- نتایج مدل به کیفیت و مقدار داده وابسته‌اند.
- ارزیابی زمانی اولیه جایگزین بک‌تست کامل و مستقل نیست.
- نتایج چهار ساعت بعد بر اساس قیمت بسته‌شدن سنجیده می‌شوند؛
  این ارزیابی شبیه‌سازی دقیق برخورد حد ضرر و هدف نیست.
- کارمزد، اسلیپیج، نقدشوندگی لحظه‌ای و دستکاری بازار می‌توانند
  نتیجه واقعی را تغییر دهند.
- آدرس قرارداد و غیرمیم‌بودن هر پروژه باید مستقل بررسی شود.
- GitHub Actions ممکن است اجرا را با تأخیر انجام دهد.
